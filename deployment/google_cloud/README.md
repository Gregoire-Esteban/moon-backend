## Google Cloud Deployment

Rely on Google Cloud resources to deploy the moon app.

### Prerequisites

- 2 Google Cloud projects : one for the dev/test environment, the other for the production environment 
- The [Google Cloud CLI](https://docs.cloud.google.com/sdk/gcloud) (don't forget to run `gcloud init` for the authentication steps)

> ***NOTE***: You can update the LOCATION environment variable set in this folder's *mise.toml* file or provide and configure the CLI as you see fit.
